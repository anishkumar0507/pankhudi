# pankhudi

Two website demos for Pankhudi, Sakchi Market, Jamshedpur.

| Path | Demo |
|---|---|
| `/` | Landing page linking both demos |
| `/fashion/` | Ladies fashion + bridal, built with the store's real photos |
| `/bridal/` | Luxury bridal boutique, designed with Google Stitch (AI imagery) |

Static HTML, no build step. On Vercel: import the repo, Framework Preset "Other", leave build command and output directory empty.
